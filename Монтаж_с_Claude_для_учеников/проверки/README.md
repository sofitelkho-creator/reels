# Проверки для монтажа — как запускать

Нужно: ffmpeg и ffprobe в PATH, Python 3.10+, numpy и распознавание речи:
- Mac на M-чипе — `pip install mlx-whisper`;
- остальные — `pip install faster-whisper`.

Модель по умолчанию — `large-v3-turbo`, другую можно задать переменной `WHISPER_MODEL`, например `small`: быстрее, но хуже.

| Скрипт | Что делает | Результат |
|---|---|---|
| `1_расшифровать.py ИСХОДНИК` | куски речи между паузами, время каждого слова, галлюцинации помечены | `ИСХОДНИК.chunks.json` + список кусков |
| `2_выбрать_дубли.py …chunks.json` | группы дублей, последняя полная попытка, без галлюцинаций, мата и «раз-раз» | `ИСХОДНИК.keep.json` — можно править руками |
| `3_нарезать.py ИСХОДНИК …chunks.json …keep.json [--speed 1.2]` | нарезка по реальной тишине, паузы ≤ ~0,25 с, ускорение | `ИСХОДНИК_нарезка.mp4` + `ИСХОДНИК.edl.json` (слова со временем в нарезке) |
| `4_проверить.py …edl.json` | ворота нарезки: повторы, фальстарты, срезанные слова, паузы, огрызки, прослушка | «НАРЕЗКА ПРОЙДЕНА» или список «!!» со временем |
| `5_безопасная_зона.py РОЛИК --at 1 5 9` / `--every 2` | кадры с интерфейсом Instagram поверх | `РОЛИК_зона_<время>.png` |
| `6_громкость.py РОЛИК [--music трек --out итог.mp4]` | громкость голоса, музыка на 18 дБ тише, итог −14 LUFS | числа или готовый файл с музыкой |

**`keep.json`:**
- `keep` — начала (`a`) нужных кусков из `chunks.json`;
- `trim` — взять из куска только часть: `{"17.61": [18.32, null]}` значит «из куска, который начинается на 17,61 с, взять всё начиная с 18,32 с». Так вырезается фальстарт в начале куска. Второе число — где закончить, `null` — до конца.

**Доказательство ложной тревоги:** строка в `ИСХОДНИК.proof.txt`, например `2.43: «весь мир… весь мир» — повтор по сценарию, проверено по тексту`. Одна строка — одна принятая тревога.

Проверено на двух настоящих исходниках:
- 3:40 с 20 дублями и 5 запинками;
- 2:01 с 9 галлюцинациями распознавания и фальстартом внутри куска.

Выбор дублей совпал с ручным, все запинки пойманы.
